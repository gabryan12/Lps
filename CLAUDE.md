# Regras do projeto

## Vídeo

Sempre que o usuário mencionar "vídeo" (criar, editar, renderizar, animar etc.), invoque a skill `remotion-best-practices` (via Skill) antes de qualquer outra coisa e siga as instruções dela. Use Remotion como padrão para vídeos, a menos que o usuário peça outra ferramenta explicitamente.
